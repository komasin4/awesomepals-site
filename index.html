LLM 서비스 · AI 인프라

폐쇄망에서도 클라우드에서도 돌아가는 LLM 서비스를 만듭니다.

멋진친구들은 30년 차 개발자 박정현의 1인 개발 스튜디오입니다.
챗봇, 업무 자동화, 기존 시스템 연동까지 설계한 사람이 구현도 직접 맡습니다.

프로젝트 문의하기 진행 중인 계약이 있어 일정은 협의 후 정합니다.
01

하는 일

LLM 챗봇·플랫폼 구축

온프레미스 LLM이나 OpenAI, Azure OpenAI를 연동한 챗봇을 설계부터 구축합니다. 문서 파싱부터 벡터·그래프 DB 기반 RAG, 카카오 챗봇 채널 연동, 기존 레거시 시스템과 잇는 게이트웨이까지 다룹니다.

폐쇄망 쿠버네티스 운영

외부망이 막힌 엔터프라이즈 환경에서 배포하고 운영합니다. 모델과 이미지를 미리 반입하는 절차를 만들고, 파드에서 노드까지 장애를 추적합니다.

아키텍처 설계와 개발 PL

전체 아키텍처를 잡고, 개발 PL로서 개발자들을 리드하면서 실무 개발을 함께 합니다. Spring Boot가 주력이지만 FastAPI를 비롯해 프로젝트에 맞는 기술로 구현합니다.

02

해온 일

2025.08 – 현재

LLM 챗봇 플랫폼 개발

고객사 내부에 설치해 쓰는 온프레미스형 플랫폼으로 시작해, 최근에는 AWS에 올리는 작업을 진행하고 있습니다. 문서를 파싱, 청킹, 태깅, 임베딩해 벡터 DB와 그래프 DB에 저장하고, 챗봇이 RAG로 답변하도록 만들었습니다. 시스템 설계와 DB 설계, 개발 총괄, 실무 개발을 맡고 있습니다.

2025.11 – 2026.05

신용평가사·정부출연 연구기관 AI 챗봇 구축

신용평가사와 정부출연 연구기관에 AI 챗봇을 구축했습니다. 신용평가사 프로젝트에서는 기존 레거시 서비스와 챗봇 플랫폼을 잇는 AI Gateway 모듈을 개발했습니다.

2025.04 – 2025.08

기업 신용평가 기관의 평가 의견 작성 자동화

평가 의견 작성을 LLM으로 자동화했습니다. 온프레미스 LLM 연동과 LangChain 기반 RAG를 개발했고, 시스템 설계부터 개발 총괄까지 맡았습니다.

2024.08 – 2025.02

AI 챗봇 서비스 개발

OpenAI 연동, LangChain 기반 RAG, 카카오 챗봇 채널 연동을 개발하고 CI/CD와 Docker 배포까지 연결했습니다.

2024.02 – 2024.07

화장품 대기업 AI 챗봇 프로젝트

시스템 설계와 DB 설계, 개발 총괄, 실무 개발을 맡았습니다. Azure OpenAI 연동, LangChain 기반 RAG, 카카오 챗봇 채널 연동을 개발했습니다.

2023.05 – 2023.11

범정부 콜센터 통합 프로젝트

상담 애플리케이션의 프론트엔드(Vue.js)와 백엔드(Spring Boot)를 개발했습니다.
